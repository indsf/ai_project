**S1 필수 기능**
- **약품 카탈로그 관리:** 약품 마스터 정보(이름, 카테고리, 단위 등) 등록/조회
- **최소 비치 기준 관리:** 선박별 약품 최소 비치 수량 설정/조회
- **재고 입고(로트 단위):** 로트번호, 수량, 유효기한을 기록하여 입고 처리(동일 약품의 서로 다른 유효기한 로트 허용)
- **약품 사용(출고) 기록 — FEFO:** 유효기한이 가장 임박한 로트부터 차감(단일 사용 요청이 여러 로트에 걸쳐 차감될 수 있음)
- **재고 현황 조회:** 선박별 현재 재고, 최소 기준 대비 부족 여부, 유효기한 임박 항목 조회
- **사용 이력 조회:** 누가(`User-ID` 헤더 기준), 언제, 어떤 약품을 얼마만큼 사용했는지 추적

**제외 범위(명시된 내용)**
- 발주/주문 관리 시스템
- 비동기 처리 / 이벤트 버스 / 배치 작업
- 선종별 필수 약품 목록 관리
- 인증·인가(단, 사용자 식별은 HTTP 헤더 `User-ID` 가정)

**모호한 요구사항**
- "선박의 최소 비치 기준"의 적용 범위: 선박 단위인가(개별 선박), 선단/회사 단위인가(전역 적용), 기간(항해별/상시) 등 미정
- 최소 비치 항목의 단위(정수 개수 vs 포장 단위 vs 투약 단위)와 단위 변환 규칙 미정
- FEFO 구현의 세부 규칙: 동일 만료일 로트 간 우선순위(입고순 FIFO? 로트번호 순?), 유통기한 시간이 포함되는지(일 단위인지 시분초인지)
- 사용 요청의 원자성 범위: 요청 시 부족하면 부분 출고 허용 여부(부분처리 + 부분 실패 행동) 미정
- 유효기한 지난(Expired) 재고의 처리 방식: 조회에서 제외 vs 별도 표시 vs 자동 폐기/격리(삭제가 아닌 상태 변경) 미정
- 로트 식별자 범위와 중복성: 동일 선박에서만 고유인지, 전역 고유인지 미정
- 시간대/타임스탬프 기준과 유효기한 비교 시점(선박 현지시간/UTC) 미정
- 사용자 식별 체계의 권한/정합성: `User-ID` 값의 신뢰성, 존재하지 않는 사용자로의 기록 허용 여부 미정

**설계 결정이 필요한 사항**
- 최소 비치 정책 모델과 물리적 재고 모델의 관계 정의: (예) 규칙(Policy) 테이블별 보관 vs SKU별 단순 값
- 재고 차감 기록 구조: 사용 이력에 어느 정도로 로트-소모 매핑을 저장할지(총량만 vs 로트별 소모 내역 상세 기록)
- 부족 시 처리 전략: 즉시 실패(거부) / 부분 허용(부분 출고 + 백오더 표기) / 자동 알림과 함께 트랜잭션 롤백
- 만료 재고 처리 정책: 조회 포함 기준(임박/만료 포함 여부), 자동 폐기(상태 변경) 주기와 책임 주체
- 동시성 제어 전략: DB 레벨 `SELECT ... FOR UPDATE`(행 잠금) vs 낙관적 잠금(버전 필드) vs serializable 트랜잭션, 성능·운영 트레이드오프
- 단위·포장 처리 방식: 포장 단위와 정수 단위 변환 규칙, 반올림/절단 정책
- 로트 유효성 검사 규칙: 입고 시 과거 유효기한 거부 vs 허용(단, 상태 'expired')
- 유효기한 비교의 시간 기준(UTC 권장) 및 타임스탬프 저장 규칙
- 이력의 보존 기간 및 삭제 정책(감사 요건 고려)

**예상 Edge Case**
- 동시성으로 인한 음수 재고(동시 사용 요청이 동일 로트/재고를 차감하는 경우)
- 단일 사용 요청이 여러 로트를 가로지를 때 일부 로트에서 부족 발생(부분 충족)하는 경우
- 모든 로트가 만료되어 사용 요청을 처리할 수 없음(만료 재고는 차감 불가)
- 동일 만료일 다수 로트에서 우선순위 결정 문제
- 입고된 로트의 수량이 0이거나 음수로 들어오는 잘못된 데이터
- 백데이팅(backdated) 입고/사용: 과거 일자로 입고/사용이 기록되어 재고·이력 왜곡 발생
- 로트 중복 등록(같은 로트번호가 재사용되었을 때) 또는 식별자 충돌
- 최소 비치 기준 변경 시점과 재고 상태의 일관성(변경 전/후 알람 처리)
- 네트워크/DB 장애로 트랜잭션 중복 재시도 시 이중 차감(아이디엠포턴시 부재)
- 시간대 경계(UTC 자정 등)로 인해 유효기한 임박 판단이 달라지는 경우
- 대량 출고 요청(여러 SKU, 대량 수량) 시 성능·락 경합 문제
